# Задачи для разработки 

1. В таблицы Состав компонентов нужно добавить новое поле (Процент %) - отображать сколько процентов составляет данный ингридиент от основной массы 
2. В компонент Вакумация добавить еще одну кнопку (Запустить таймер) - кнопка будет просто запускать обратный отсчет без запуска вакумации. У кнопки два состояния Старт/Сбросить. При сбросе счет сбрасывается 
3. Когда компонент Вакумация становится на весь экран - нужно сделать круглый таймер компонент немного больше 
4. На страницу дашборда нужно добавить Список задач (то есть красок которые нужно изготовить). Пользователь создают задачу для создания краски. После выбирает ее и запускает. Пользователь должен указать в задаче Цвет краски, и литраж.
