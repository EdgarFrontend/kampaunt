# Правила проекта Kampaunt

## Архитектурная документация

**Перед любым исследованием проекта** (структура, архитектура, типы, API, стили, компоненты, бизнес-логика) — **обязательно сначала прочитай** файл `.agents/PROJECT_ARCHITECTURE.md`.

Этот файл содержит полную документацию проекта:
- Стек технологий и зависимости
- Дерево директорий с описанием каждого файла
- Архитектура: навигация, иерархия компонентов, управление состоянием
- Все типы данных (TypeScript interfaces)
- API эндпоинты и схема базы данных (Prisma)
- Дизайн-система (CSS custom properties, глобальные классы, CSS Modules)
- Бизнес-логика: калькулятор, вакумация, история, цвета
- Нюансы и особенности (устаревшие хуки, неиспользуемые зависимости и т.д.)

**Не сканируй проект заново** если информация уже есть в этом файле. Обращайся к исходным файлам только если нужны детали, которых нет в документации, или если документация могла устареть после внесённых изменений.

**При внесении значительных изменений** в проект (новые файлы, компоненты, типы, API) — **обнови PROJECT_ARCHITECTURE.md** чтобы он оставался актуальным.
